# Kasi Mart Data Engineering Project

## Project Overview

This project demonstrates a simple data engineering and analytics workflow using **Snowflake**. The project uses sales data from Kasi Mart to load customer, product, and order information into Snowflake and perform basic revenue analysis using SQL.

The project focuses on three source datasets:

* **Customers** - customer details and signup information
* **Products** - product details, categories, and unit prices
* **Orders** - customer purchases, order dates, products, and quantities

The data is loaded into a structured Snowflake database and schema, after which SQL queries are used to analyse sales performance.

## Technology

* Snowflake
* SQL

## Snowflake Structure

The project uses the following database and schema:

```text
DE_PROJECT1
└── KASI_MART
    ├── CUSTOMERS
    ├── PRODUCTS
    └── ORDERS
```

The tables contain appropriately defined data types for identifiers, dates, quantities, and monetary values.

## Data Loading

The CSV files are loaded into Snowflake using an internal Snowflake stage and `COPY INTO` statements.

The three datasets loaded are:

| Dataset       | Snowflake Table | Expected Records |
| ------------- | --------------- | ---------------: |
| customers.csv | CUSTOMERS       |               50 |
| products.csv  | PRODUCTS        |               20 |
| orders.csv    | ORDERS          |              150 |

The loaded record counts were verified using SQL.

## SQL Analysis

Four SQL queries were developed to analyse the sales data:

### 1. Order-Level Revenue

Joins orders with customer and product information and calculates revenue for each order line using:

```text
quantity × unit_price
```

### 2. Total Revenue per Customer

Aggregates order revenue by customer to identify the total revenue generated by each customer.

### 3. Total Revenue per Product Category

Aggregates revenue by product category to compare the contribution of different categories.

### 4. Top 5 Customers by Total Spend

Ranks customers according to their total spend and returns the five customers with the highest spending.

## Purpose

The purpose of this project is to demonstrate the ability to:

1. Create and structure a database and schema in Snowflake.
2. Load CSV datasets into Snowflake tables.
3. Use appropriate data types for structured data.
4. Write SQL queries involving joins, calculations, aggregation, grouping, sorting, and limiting results.
5. Analyse sales data to produce useful business insights.
